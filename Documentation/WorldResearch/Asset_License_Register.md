## 1. Non-Infringement & Originality Statement

Project **SparkVision** is an independent, non-commercial academic game project developed for educational and historical documentation purposes.

### Strict Compliance with Commercial IP Boundaries:
* **Where Winds Meet (Everstone Studio / NetEase Games)**: Used strictly as a benchmark standard for visual presentation, atmospheric lighting depth, camera composition, and environmental density. **Zero proprietary assets, 3D meshes, textures, animations, shaders, audio files, UI graphics, or code from Where Winds Meet are contained in or used by SparkVision.**
* **Ghost of Tsushima (Sucker Punch Productions / Sony Interactive Entertainment)**: Used strictly as an aesthetic reference for natural lighting, foliage wind movement, and cinematic framing. **Zero proprietary assets, models, materials, or code from Ghost of Tsushima are present in this repository.**
* **Originality**: 100% of the custom architectural 3D meshes, static mesh actors, C++ game logic, shader graphs, level layouts, and documentation were authored directly within this repository using Blender, procedural Python generation pipelines, and native Unreal Engine 5.8 authoring tools.
